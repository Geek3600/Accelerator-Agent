# 算核库、工具链和部署清单

## 1. 已形成的算核库

算核库主目录：

```text
src/main/scala
```

主要算核模块：

| 目录 | 内容 |
| --- | --- |
| `LayerNormQ` | 量化 LayerNorm |
| `QKVLinear` | Q/K/V 投影算核 |
| `DM` | Q·K attention score 计算 |
| `Softmax` | Softmax 计算 |
| `DM2` | P·V attention value 计算 |
| `OutLinear` | Attention output projection |
| `ResAdd` | Attention 后残差 |
| `FFNUp` | FFN 升维 + ReLU 融合 |
| `FFNDown` | FFN 降维 |
| `ResAdd2` | FFN 后残差 |
| `QuantCommon` | FP32/INT8/pack/量化公共组件 |
| `TempAdapter` | 输入地址和 token/beat 适配 |
| `ResMEM` | Attention 历史数据相关模块 |
| `Top.scala` | 完整 Transformer block 顶层集成 |

测试目录：

```text
src/test/scala
```

```text

```

```text

-> Chisel elaboration
-> generated/Top.sv
-> generated/Top_vivado.sv
-> deliverables/vivado_opt_acc_core_ip/hdl/opt_acc_core.sv

-> bitstream
```



## 6. PPT 材料包包含策略

本材料包包含：

- 中文项目总结；
- PPT 页纲；
- 算核库/工具链/部署清单；
- 关键项目文档；
- Chisel 算核库源码；
- 关键验证脚本；
- 关键 board 部署脚本；
- 小型配置和 manifest。

本材料包不包含：

- bitstream；
- DDR image；
- Office runtime tar；
- 模型压缩包；
- Vivado 巨大网表；
- 仿真 build 目录；
- 临时日志和 cache。
